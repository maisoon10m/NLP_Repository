# Tweet Generation Using Bigram Language Models

This lab builds a Maximum Likelihood Estimation (MLE) bigram language model to generate tweets using a dataset of random tweets from Pakistan.

## Tasks

* Load and inspect the tweet dataset.
* Remove retweet markers, hashtags, URLs, mentions, and emojis.
* Tokenize the cleaned tweets.
* Train an MLE bigram language model using NLTK.
* Generate new tweets from the trained model.
* Evaluate the model using perplexity.
* Calculate \(P(\text{is}\mid\text{pakistan})\).
* Calculate the perplexity of the word `pakistan`.
