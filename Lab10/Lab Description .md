
## Lab 10: Introduction to Machine Translation

This lab introduces **Neural Machine Translation (NMT)** using an **Encoder–Decoder LSTM** architecture to translate English sentences into French.

### Key Concepts
- **Tokenization and Padding:** Prepare text sequences for the model.
- **Embedding Layer:** Convert word indices into dense vectors.
- **Encoder LSTM:** Capture information from English sentences.
- **Decoder LSTM:** Generate French word predictions.
- **Softmax:** Predict probabilities for French vocabulary words.

### Implementation
- Preprocessed an English–French translation dataset.
- Built and trained an Encoder–Decoder LSTM model using TensorFlow/Keras.
- Evaluated model accuracy and tested translations.

**Outcome:** Gained practical experience in sequence-to-sequence translation and identified limitations of basic LSTM models in producing accurate translations.
